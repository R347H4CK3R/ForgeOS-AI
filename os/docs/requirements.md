# ForgeOS AI OS requirements

- Tablet-first launcher and navigation.
- Multi-window: split-screen, freeform resizing, app task switcher, keyboard/mouse input.
- Wi-Fi and Bluetooth device management through system services.
- Touch and stylus/keyboard where supported.
- Adopted SD storage with encrypted app-private model and project directories.
- Tailscale integration through installed app or supported service.
- Desktop Commander remote bridge through an authorized Windows/Linux host; no unsupported claim of a native Android agent.
- External display: verify USB-C DisplayPort Alt Mode or compatible USB display hardware before promising HDMI.
- Local inference constrained to approximately 3 GB RAM, with remote acceleration optional.
- No forced cloud subscription for core tools.
- No firmware flash before user UI approval, backup and recovery validation.
